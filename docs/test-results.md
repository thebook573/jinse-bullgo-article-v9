## 响应式

`responsive-check.json` 记录桌面 Chromium 内同源 iframe 的十种 CSS 视口。只在 QA 路由隐藏滚动条，以使内容视口宽度等于指定值；没有整体 transform 缩放页面。

| 视口 | 横向溢出 | 已加载损坏图片 | 底部操作栏 |
| --- | --- | --- | --- |
| 1920×1080 | 无 | 无 | sticky |
| 1440×900 | 无 | 无 | sticky |
| 1366×768 | 无 | 无 | sticky |
| 1280×800 | 无 | 无 | sticky |
| 393×852 | 无 | 无 | fixed |
| 390×844 | 无 | 无 | fixed |
| 375×812 | 无 | 无 | fixed |
| 360×800 | 无 | 无 | fixed |
| 320×568 | 无 | 无 | fixed |
| 844×390 | 无 | 无 | 平板布局 sticky |

首屏和长页截图已人工查看。390 与 375 宽度下导航、标题、作者、正文、图片、固定底栏没有观察到重叠。正文图片在 390 宽度下为约 360×193 和 360×120，与原始 600×322 和 600×200 比例一致。其余尺寸进行了 DOM 溢出/字体/图片检查，未声称逐张完成原站视觉比对。

这不是移动 User-Agent 或真实手机模拟。真机软键盘、iOS Safari、刘海安全区域和原站手机截图对照仍待验证。
