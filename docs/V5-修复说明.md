## 部署提醒

将整个项目上传 GitHub，Cloudflare Pages `Build command` 为 `npm run build`，`Build output directory` 为 `dist`。`SITE_URL` 可选地设置为正式 HTTPS 自定义域名；不设置时会使用 Cloudflare Pages 的 `CF_PAGES_URL`。不要直接上传本地预览生成的 index.html 来替代构建。
