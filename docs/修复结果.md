# 本次修复结果（2026-10-22）

## 原因

原始压缩包只有 `content/page.html` 模板文件，不含可直接在根目录查看的构建结果。若使用 VS Code Live Server 打开此模板，就会看到 `{{TITLE}}`、`{{ARTICLE}}`、`{{RELATED}}`。这与 HTML 模板替换逻辑有关，并不能仅凭截图断言整个项目内容未写入。

## 已修复

- 将原始页面模板改名为 `content/page.template`，避免误点模板当作网页。
- 在项目根目录附带两个已渲染的 HTML：`index.html`、`blockchain/3731109.html`；它们都没有模板变量。
- 新增 `npm run preview:ready`，修改数据/模板后可重新生成上述预览文件。
- 修复本地 `file://` 直接预览时分享脚本的 URL 解析兼容性；正常 HTTP 服务仍使用当前站点域名。
- 保留并正确引用 ZIP 内的两张正文配图、12 条采集时的相关热文与全部图片资源。
- 把原有简短摘要改为较完整的文章导读，但不能替代原文章逐字全文。
- 保留 Cloudflare Pages 的生产构建，实际的 SITE_URL/CF_PAGES_URL 在正式构建时静态注入 Open Graph 元信息。
- 新增防回归自动测试。

## 限制与部署注意

- ZIP 包内原文只有摘要材料，所以本版仍是**导读版**，并非原文全部段落。
- 真实 Telegram、DeBox、Envo 预览尚未测试，因为没有你实际部署的站点地址；模拟 User-Agent 并不等于真实平台访问。
- 本地 `index.html` 的 OG 地址是本机预览用的 localhost；**Cloudflare Pages 一定要使用 `npm run build`，发布目录 `dist`**。不要把源代码根目录当成静态上传目录，否则社交卡片会指向本机。
- 如要实现逐字复制完整原文，须提供你有权使用的正文原稿。
